# Data

The RNA-seq dataset used in this project is publicly available from the NCBI Gene Expression Omnibus (GEO):

- **GEO accession:** [GSE260786](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE260786)
- **Organism:** Homo sapiens
- **Tissue:** Skeletal muscle
- **Data type:** Bulk RNA-seq

The original data are not redistributed in this repository.
Please download the processed data directly from GEO.
